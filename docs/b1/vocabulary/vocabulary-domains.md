# Vocabulaire B1 — domaines lexicaux et modules associés

Seize domaines lexicaux utiles à un adulte vivant ou souhaitant vivre en
France. Chaque domaine est rattaché aux modules qui le mobilisent
(`content/b1/curriculum.md`), pour garantir une réutilisation progressive du
vocabulaire plutôt qu'un empilement de listes isolées.

## Ce que chaque module doit préciser (rappel éditorial)

Pour chaque module, la section « C. Vocabulaire » distingue systématiquement :

1. **Vocabulaire principal** — 10 à 25 mots ou expressions, avec le genre
   pour les noms (le/la/l'/les) et l'infinitif pour les verbes.
2. **Expressions utiles** — tournures idiomatiques ou figées de la situation
   (ex : « prendre rendez-vous », « c'est-à-dire »).
3. **Verbes utiles** — verbes-clés du module, à l'infinitif, avec leur
   construction si elle n'est pas transparente (ex : « s'occuper de »).
4. **Connecteurs utiles** — connecteurs logiques ou chronologiques
   pertinents pour la situation du module.

## Principe de réemploi

Un mot appris dans un module (ex : « le loyer » en Module 4) peut être
réutilisé sans être re-glosé dans un module ultérieur (ex : Module 19,
budget) — c'est volontaire : le programme est conçu comme un tissu, pas
comme une suite de listes indépendantes.
